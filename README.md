Mobile-optimized sensory and emotional grounding toolkit designed for neurodivergent individuals, featuring interactive tactile visuals, breathing guides, and calming audio.

Built by **TYSON Media Group**.

---

## Features

- **Sensory Visuals**: Procedural generative WebGL and Three.js visualizers for calming tactile feedback.
- **Grounding Tools**: Interactive breathing paces and tactile pacing controls.
- **Mobile First**: Optimized touch interactions designed for smartphones and tablets.

---

## Getting Started

```bash
# Clone the repository
git clone https://github.com/TYSONMediaGroup/M-AUDHD.git
cd M-AUDHD

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
